1调优驾驶舱你的构想 · 已实现
调优不是流式打字，而是产出曲线与数据：每轮保存检查点，可在任意检查点停止、换参数、长出新分支，各分支结果并存可对比。曲线实时更新。

设计说明

定位、信息架构、设计 token、关键决策与落地边界

01产品定位

这是一整套大号的售前 + 售后服务：用户买鲲鹏服务器，开箱即用一整套 Agent 平台。核心主张 = 黑灯工厂化——任务丢进去，后台自动跑，用户只需看面板；三个任务型 Agent（/agent:migrate 源码迁移、/agent:develop 源码开发、/agent:tuning 参数调优）＋ 一个总控 Watchdog（/goal）负责分解、监测与结果串联。
  • 工作区双轨：本机文件系统 ↔ openEuler 沙箱（aarch64 / QEMU），迁移开发在沙箱里真跑
  • 记忆层 og-memory 是幕后英雄：不直接干活，但每次任务都站在上次经验上
  • 调优不走「对话流式输出」老路：出曲线、出数据、存检查点、可分支、可对比

02信息架构

单页五视图：集成主站（可交互原型）→ 主页面 ×6 → 调优 ×4 → Watchdog ×4 → 说明。主站为三栏工作台（方案 A）：左栏会话队列 + 左下工作区栏，中栏投喂 / 详情，右区任务细节；后台会话用呼吸灯侧栏（草图②方案1），任务步骤用内联展开（草图①方案2）。

04关键决策

  • 白底 + 青蓝：直接沿用两张草图的浅色体系；「黑灯工厂」是运营理念（无人值守、后台自动跑）而不是视觉主题，不需要用深色表达
  • 记忆的体现：不单独占大屏，用「顶栏状态 + 会话记忆徽标 + 详情页参考记忆 + 记忆库抽屉」四处轻量化存在，保持幕后英雄的定位
  • 调优交互：停止当前 Agent → 在某检查点换参数 → 长分支，把「后悔药」和「并行实验」做成第一公民交互
  • Watchdog：DAG 表达调度依赖，串联链表达结果装配，达成度仪表表达整体状态
  • 工作区栏放左下：与会话队列同列同屏，切换「本机 / openEuler 沙箱」随时可见当前工作环境
